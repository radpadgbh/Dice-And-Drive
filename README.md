Game Dice And Drive Demo

## How to play
1. เลือก loadout skills,combos,passive และ start
2. roll dice ถ้าเกิน 11 จะบังคับ skill type S
3. เลือก skill (A/B/C/D/S)
4. Clash Win/Parry/Lose

## Core Rules
Player \ Enemy	A (Attack)	B (Break)	C (Counter)	D (Utility)	S (Stance)
A (Attack)	    PP	        WL	      LW	        WL	        WW
B (Break)	      LW	        PP	      WL          WL	        WW
C (Counter)    	WL	        LW       	LL        	LW	        LW
D (Utility)	    LW	        LW	      WL        	WW	        WW
S (Stance)    	WW        	WW      	WW        	WW        	WW
